# Roadmap

Проект развивается короткими продуктовыми итерациями. Каждый milestone должен давать
пользователю законченный новый уровень возможностей, а не просто объединять набор
технических задач.

`ROADMAP.md` показывает направление развития продукта. Актуальный состав работ и
фактический прогресс остаются в GitHub milestones и связанных issue.

Целевые даты активных milestones являются ориентирами планирования, а не гарантией
выпуска в конкретный день.

## v0.1 — MVP

[Milestone v0.1 — MVP](https://github.com/ashikov/uo-request-generator/milestone/1)

Первый работающий и проверенный основной сценарий генерации и копирования заявки.

Пользователь описывает одну проблему обычным языком, сервис формирует готовую
заявку в управляющую организацию и позволяет скопировать результат. Этап
подтверждает базовую ценность продукта без требований полноценной публичной
эксплуатации.

Состав milestone завершён.

## v0.2 — Public launch

[Milestone v0.2 — Public launch](https://github.com/ashikov/uo-request-generator/milestone/2)

Целевая дата: **30 августа 2026 года**.

Переход от работающего MVP к публичной beta-версии, которой можно пользоваться в
реальном основном сценарии.

Основные направления этапа:

- безопасный публичный запуск и защита платной генерации
- воспроизводимый deployment и необходимые эксплуатационные проверки
- минимальная наблюдаемость без раскрытия пользовательских текстов
- необходимая подготовка по обработке данных, приватности и пользовательским
  уведомлениям
- проверенные предметные нормативные модули для распространённых проблем общего
  имущества: входных дверей, освещения, уборки, кровли, вентиляции и лифтов
- единый явный способ подтверждения пользователем предмета проблемы вместо
  отдельного специального флага для каждого нормативного модуля

К концу этапа сервис должен быть пригоден для публичного использования, а готовая
заявка — заметно полезнее универсального переписывания текста благодаря заранее
проверенным нормативным основаниям для наиболее частых ситуаций.

## v0.3 — It Just Knows

[Milestone v0.3 — It Just Knows](https://github.com/ashikov/uo-request-generator/milestone/3)

Целевая дата: **30 сентября 2026 года**.

Следующий шаг — сделать нормативные возможности менее заметными как внутренний
механизм и более естественными для пользователя.

Пользователь по-прежнему просто описывает проблему обычным языком. Сервис сам
распознаёт подходящий предмет проблемы и, когда данных достаточно, предлагает
применимый нормативный модуль.

Пользователь явно подтверждает предложение, а backend независимо проверяет
применимость перед добавлением специального нормативного текста. Ошибка
классификации сама по себе не должна приводить к применению неподходящего
нормативного основания.

Цель этапа — убрать необходимость заранее понимать внутренние категории сервиса,
не превращая LLM в источник законодательства и не ослабляя fail-closed поведение.

## Далее

После стабилизации публичной beta следующие крупные направления будут определяться
по фактическому использованию сервиса и подтверждённым пользовательским сценариям.

Среди возможных направлений:

- повторные обращения в управляющую организацию
- жалобы на действия или бездействие управляющей организации
- поддержка более сложных коммунальных ситуаций, где нужно учитывать исполнителя
  услуги
- локальная история готовых заявок
- дальнейшее уменьшение количества ручных действий пользователя

Эти направления не считаются обещанными релизами, пока для них не создан отдельный
milestone с определённым продуктовым результатом.
